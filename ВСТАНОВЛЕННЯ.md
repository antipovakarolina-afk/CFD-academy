# Як поставити все на свій комп'ютер

Відкрий програму для команд:
- **Mac:** натисни `Cmd + Пробіл`, введи «Terminal», Enter.
- **Windows:** натисни кнопку «Пуск», введи «PowerShell», Enter.

Потім копіюй рядки нижче по одному і натискай Enter.

## Mac

```bash
# 1. Homebrew — «магазин програм» для Mac (якщо ще немає)
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# 2. ffmpeg, Python, Node.js
brew install ffmpeg python node

# 3. Whisper
pip3 install faster-whisper
```

## Windows

```powershell
# 1. ffmpeg, Python, Node.js (winget вже вбудований у Windows 10/11)
winget install Gyan.FFmpeg
winget install Python.Python.3.12
winget install OpenJS.NodeJS.LTS

# Закрий і знову відкрий PowerShell, потім:
# 2. Whisper
pip install faster-whisper
```

## Перевірка

```bash
ffmpeg -version
python3 --version     # на Windows: python --version
node --version
```

Якщо кожна команда показала номер версії — все стоїть.

## Перший запуск розпізнавання

Поклади відео в теку `originals/` і запусти (з теки студії):

```bash
python3 tools/transcribe.py originals/моє_відео.mp4
```

Перший раз програма завантажить модель (~500 МБ) — це один раз. Далі працює без інтернету.
Субтитри з'являться в `output/`.
