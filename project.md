# Монтажна студія — паспорт проєкту

Цей файл — наша спільна пам'ять. Сюди записуємо, хто ти, про що блог і які правила монтажу ми погодили.
Коли домовимось про нове правило — я його сюди допишу.

## Хто я

- Автор(ка) освітнього проєкту **CFD Academy** («Learn Trading from Zero»).
- Не програміст — пояснення потрібні простими словами, без технічного жаргону.
- Мова спілкування: українська.
- Комп'ютер: _уточнити — Mac чи Windows_.

## Про що блог

- Навчання трейдингу CFD з нуля для початківців (є сайт-курс `CFD_Academy_Website.zip`).
- Формат: освітній, **не інвестиційна порада**, без закликів до угод і без «живих» котирувань.
- _Уточнити: мова відео, платформи (YouTube / Reels / TikTok), довжина роликів, стиль._

## Структура студії

| Тека | Що там лежить |
|------|---------------|
| `originals/` | Сирі записи з камери чи телефона. **Оригінали ніколи не змінюємо і не видаляємо.** |
| `assets/music/` | Музика |
| `assets/fonts/` | Шрифти |
| `assets/images/` | Картинки, логотипи, заставки |
| `output/` | Готові змонтовані відео |
| `tools/` | Допоміжні програми (наприклад, розпізнавання мови) |

Великі відеофайли з `originals/` та `output/` не завантажуються на GitHub (вони занадто важкі) — лише зберігаються на комп'ютері.

## Правила монтажу (погоджені)

1. Оригінали в `originals/` лише читаємо — працюємо з копіями, результат кладемо в `output/`.
2. У кожному відео про трейдинг — нагадування, що це навчальний матеріал, а не інвестиційна порада.

_Далі — поки порожньо. Додамо, коли домовимось (субтитри, темп, музика, формат кадру, заставки тощо)._

## Інструменти

- **ffmpeg** — «двигун» для різання, склеювання та конвертації відео.
- **Python** — мова, на якій працюють допоміжні програми.
- **Node.js** — запасний інструмент для майбутніх задач.
- **Whisper (faster-whisper)** — розпізнає мову з відео й робить субтитри. Працює локально, розуміє українську.
  Модель за замовчуванням — `medium` (перевірено: добре розуміє українську).
  Запуск: `python tools/transcribe.py originals/моє_відео.mp4` → у `output/` з'явиться файл субтитрів `.srt`.
  Важливо: потрібна бібліотека `av` версії нижче 16 (`pip install "av<16"`), новіша ламає Whisper.
